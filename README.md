# 근무일·정액분 계산기

한 달 근무일 수와 시간외근무수당 정액분을 계산하는 웹앱(PWA)입니다.
설치 없이 브라우저에서 열 수 있고, 홈 화면에 추가하면 앱처럼 실행됩니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면과 계산 로직 전체 (CSS·JS 포함, 외부 라이브러리 없음) |
| `manifest.json` | PWA 설치 정보(이름, 아이콘, 테마 색) |
| `sw.js` | 오프라인 실행용 서비스 워커 |
| `icon.svg`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | 앱 아이콘 |

단독 실행 파일은 `allowance_calc.html` 한 개입니다. 이 파일은 매니페스트·서비스 워커 연결을 뺀
같은 앱으로, 파일을 더블클릭해 바로 열 수 있습니다.

## 사용법

1. 상단 **호봉**을 입력합니다. (기본 10호봉)
2. 달력에서 방학·재량휴업·임시공휴일·조퇴한 날 등 **근무하지 않은 평일을 눌러 표시**합니다.
   한 번 더 누르면 해제됩니다. 주말과 공휴일은 눌리지 않습니다.
3. 오른쪽(모바일은 아래)에서 **근무일 수**, **조퇴·연가 가능일**, **정액분**을 확인합니다.
4. **단가 설정**에서 호봉 구간별 단가와 기준 출근일을 바꿀 수 있습니다. **기본값 복원**으로 되돌립니다.
5. **이 달 표시 지우기**를 두 번 누르면 그 달의 표시가 모두 지워집니다.

## 계산 규칙

- 근무일 수 = 그 달 총일수 − (주말 + 공휴일 + 표시한 날), 겹치는 날은 한 번만 셉니다.
- 조퇴·연가 가능일 = max(0, 근무일 수 − 기준 출근일)
- 정액분 = ⌊⌊단가 × min(근무일 수, 기준일) ÷ 기준일⌋ ÷ 10⌋ × 10 (1원 미만 절사)
- 기본 단가: 1~19호봉 127,950원 / 20~29호봉 142,130원 / 30호봉 이상 152,580원, 기준 출근일 15일

## 공휴일

- 2024~2100년. 매년 같은 양력 공휴일 10개(신정, 삼일절, 노동절, 어린이날, 현충일, 제헌절,
  광복절, 개천절, 한글날, 성탄절)와 음력 명절(설날 연휴, 부처님오신날, 추석 연휴)을 자동으로 표시합니다.
- 대체공휴일은 다음 규칙으로 계산합니다.
  - 하루짜리 공휴일이 토·일요일이거나 다른 공휴일과 겹치면 → 그 뒤 첫 번째 평일
  - 설날·추석 연휴가 일요일이나 다른 공휴일과 겹치면 → 연휴 뒤 첫 번째 평일
  - 신정과 현충일은 대체공휴일 대상이 아닙니다.
- 임시공휴일(선거일 등)과 학교 재량휴업일은 자동 계산에 넣지 않았습니다. 달력에서 눌러 표시하세요.
- 음력 날짜는 한국 표준시 기준 합삭일과 중기(中氣)로 계산했고, 한국천문연구원 음양력 자료
  (1910~2050년)와 같은 결과인지 확인했습니다.

## 저장되는 정보

호봉, 표시한 날짜, 수정한 단가·기준일, 마지막으로 본 달을 브라우저 `localStorage`
(`workdayAllowance.v1`)에만 저장합니다. 서버로 보내는 정보는 없습니다.
브라우저 데이터를 지우면 설정도 초기화됩니다.

## GitHub Pages에 올리기

1. 이 폴더의 파일을 저장소 최상위(또는 원하는 하위 폴더)에 그대로 올립니다.
2. 저장소 **Settings → Pages**에서 배포 브랜치와 폴더를 지정합니다.
3. `https://<계정>.github.io/<저장소>/` 로 열면 됩니다. 하위 폴더에 올려도 상대 경로라 그대로 동작합니다.

`index.html`을 수정한 뒤에는 `sw.js`의 `CACHE_NAME`(예: `workday-allowance-v2`)을 올려야
이전 화면이 캐시에 남지 않습니다.
